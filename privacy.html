2. 접근·처리하는 정보

  • Google OAuth 인증 토큰과 권한 범위: 승인된 YouTube 계정에 접근하기 위해 사용합니다.
  • YouTube 채널 ID·채널명: 업로드 대상이 운영자가 승인한 채널인지 확인합니다.
  • 영상 ID·제목·설명·길이·게시 시각·공개 설정·업로드 및 처리 상태: 영상 관리와 오류 진단에 사용합니다.
  • 진단 요청 시 API가 제공하는 영상 통계(예: 조회수 등)를 저장할 수 있습니다.
  • 별도로 제작한 대본·음성·영상, 검수 기록, 파일 해시, 실행 기록과 비용 추정 기록을 처리합니다.

현재 구현은 Gmail 메시지·Google 연락처·Drive 파일에 접근하지 않으며, 시청자 신원이나 댓글 내용을 수집하지 않습니다.

3. YouTube 권한의 목적

  • youtube.readonly: 채널 소유 관계와 영상 상태·메타데이터를 확인합니다.
  • youtube.upload: 제작 영상을 우선 비공개로 업로드합니다.
  • youtube.force-ssl: 운영자의 명시적 승인에 따라 선택한 영상의 제목·설명·공개 설정 변경, 예약 설정 또는 삭제 등 지원되는 관리 작업을 수행합니다.

정기 제작은 공개 승인을 대신하지 않습니다. 공개 및 삭제 같은 관리 작업은 별도 운영자 승인을 전제로 합니다.

4. 보관 위치와 보호

인증 토큰은 운영자의 로컬 인증 파일 및 비공개 GitHub 저장소의 GitHub Actions Secrets에 보관될 수 있습니다. Secrets는 GitHub가 제공하는 암호화된 저장 기능을 사용하고, 실행 중에는 인증을 위해 사용됩니다. 인증 토큰을 공개 사이트나 소스 코드에 게시하지 않습니다.

검수·진단·운영 기록과 제작 파일은 운영자의 로컬 작업 공간 및 비공개 GitHub 저장소·Actions 저장 공간에 보관될 수 있습니다. 접근은 해당 저장소와 계정에 권한이 있는 운영자·기여자로 제한됩니다.

5. 서비스 제공자와 정보 이전

Google/YouTube는 OAuth 인증과 영상 서비스를 처리하고, GitHub는 비공개 자동화 실행·파일·기록 저장 및 이 공개 사이트의 호스팅을 제공합니다.

제작 과정에서 OpenAI는 대본 작성·검수용 텍스트, ElevenLabs는 음성 합성용 대본을 처리할 수 있습니다. Google 인증 토큰을 이 AI 제공자에게 전송하지 않습니다. 기본 제작 코드에는 YouTube API 응답을 대본 생성·음성 합성 프롬프트로 보내는 기능이 없습니다. 다만 운영자가 대화형 개발·지원 도구를 명시적으로 연결하면 진단에 필요한 기록이 그 도구에서 처리될 수 있습니다. 각 제공자의 처리는 해당 서비스의 약관과 개인정보처리방침을 따릅니다.

운영자는 Google API 사용자 데이터를 판매하거나 맞춤 광고에 사용하지 않으며, 범용 AI·머신러닝 모델의 학습·개선에 사용하지 않습니다.

Limited Use: 이 앱이 Google API에서 받은 정보를 사용하거나 다른 앱으로 이전하는 경우, Limited Use 요건을 포함한 Google API Services User Data Policy를 준수합니다.

토큰의 만료 또는 권한 철회는 기존 저장 기록이나 YouTube 영상을 자동으로 삭제하지 않습니다.

1. About the app and operator

ThinkDifferently Shorts Studio is a private video preparation and review tool used by the owner of the ThinkDifferently YouTube channel. The operator is LimSeunghyeon1, the channel is @ThinkDifferentlyLab, and the privacy contact is ljs981005@gmail.com.

The app is not a public sign-up service. This informational website does not perform Google sign-in or YouTube authorization.

2. Information accessed and processed

  • Google OAuth tokens and granted scopes, to access the authorized YouTube account.
  • YouTube channel ID and channel name, to verify the owner-approved upload destination.
  • Video IDs, titles, descriptions, duration, publication time, visibility, upload status and processing status, for management and diagnosis.
  • Video statistics returned by the API, such as view counts, may be retained when diagnostics are requested.
  • Separately created scripts, narration and video files, review records, file hashes, execution records and estimated production costs.

The current implementation does not access Gmail messages, Google contacts or Drive files, and does not collect viewer identities or comment contents.

3. Purpose of YouTube permissions

  • youtube.readonly: verify channel ownership and inspect video status and metadata.
  • youtube.upload: upload produced videos privately for review.
  • youtube.force-ssl: carry out supported management operations, such as changing a selected video’s title, description, visibility or schedule, or deleting it, following explicit owner approval.

Scheduled production does not constitute approval to publish. Publication and deletion require a separate owner-approved operation.

4. Storage and protection

Tokens may be stored in the operator’s local authorization files and GitHub Actions Secrets in the private automation repository. Secrets use GitHub’s encrypted storage and are used for authorization during execution. Tokens are not published in this website or source code.

Review, diagnostic and operational records and production files may be stored in the operator’s local workspace and private GitHub repository or Actions storage. Access is restricted to operators or contributors authorized for those accounts and repositories.

5. Service providers and transfers

Google/YouTube handles OAuth authorization and video services. GitHub provides private automation execution and file/record storage, and hosts this public website.

During production, OpenAI may process script-writing/review text and ElevenLabs may process narration text for speech synthesis. Google authorization tokens are not sent to those AI providers. The base production code does not forward YouTube API responses into script-generation or speech-synthesis prompts. If the operator explicitly connects an interactive development or support tool, records needed for diagnosis may be processed by that tool. Provider processing is subject to the respective service terms and privacy policies.

The operator does not sell Google API user data, use it for personalized advertising, or use it to train or improve generalized AI or machine-learning models.

Limited Use: The app’s use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

6. Retention

Review artifacts and produced-video artifacts in the production workflows are currently configured for 14-day retention in GitHub Actions. Execution logs follow the repository’s log-retention settings. Local files and narration caches may remain until separately removed.

The current implementation does not automatically purge API diagnostic metadata, channel/video identifiers, review records, cost records or duplicate-prevention records on a fixed schedule. Copies in Git history or backups may require separate removal. The operator must review and remove data that is no longer needed or is subject to a deletion request.

Token expiry or revoking authorization does not automatically remove existing stored records or YouTube videos.

7. Revocation and deletion requests

You can revoke this app’s access through Google Account third-party connections. Revocation prevents continued new API access using that authorization.

To request removal of app-retained data, contact ljs981005@gmail.com. After verifying the requester’s authority, the operator will remove the tokens, diagnostic data, files/caches and relevant records under their control, and review historical or backup copies where necessary. Send only minimal information, such as a public channel URL. Do not send passwords, API keys or authorization tokens.

Uploaded YouTube videos can be managed directly in YouTube Studio. Deleting app records and deleting YouTube videos are separate actions.

8. Public information and this website

Videos and associated titles/descriptions become public on YouTube when the operator approves public release. Sharing a private-review link alone does not grant another person viewing access.

This website adds no sign-in form, analytics, advertising trackers or custom cookies. GitHub Pages hosting may process request information such as IP addresses and browser information under the GitHub Privacy Statement.

This app uses YouTube API Services. Use of the app is subject to the YouTube Terms of Service. Google’s processing is described in the Google Privacy Policy.

ThinkDifferently Shorts Studio is an independent tool and is not sponsored or endorsed by Google or YouTube.
